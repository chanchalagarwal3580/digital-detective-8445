## Project Overview

This repository contains my completed work for **The Digital Detective** Diwali Independent Learning Assignment. The goal of this assignment is to explore and document how a modern computer works from the ground up:
- Understanding basic computer architecture and the IPOS (Input, Processing, Output, Storage) cycle.
- Navigating and manipulating files using the Unix command-line interface (Terminal).
- Inspecting how operating systems manage processes, storage, memory, and permissions.
- Understanding how source code is translated and executed by comparing compilers and interpreters.
- Analyzing data representation (binary, hexadecimal, decimal) and character encodings (ASCII, UTF-8), backed by a Python conversion tool.
- Practicing professional version control with Git and collaboration using GitHub (branches, commits, pull requests).
- Demystifying computer networking, DNS resolution, and the client-server lifecycle.

Each mission is documented in its own dedicated folder with clear explanations, real Terminal observations, and privacy-safe evidence.
