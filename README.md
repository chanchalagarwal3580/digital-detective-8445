## Topics Explored Summary

1. **Computer Fundamentals (IPOS Cycle)**: Tracing how data moves from hardware inputs through CPU/RAM processing to visual outputs and permanent SSD storage.
2. **Unix Command-Line Interface (CLI)**: Navigating directories, manipulating files, utilizing command flags (`-lah`), and piping data streams (`\|`).
3. **Operating System Architecture**: Monitoring running processes and daemons, analyzing Process IDs (PIDs), understanding virtual memory, and decoding POSIX file permissions (`r-w-x`).
4. **Program Execution Models**: Comparing compiled languages (C, C++) with interpreted languages (Python) regarding binary generation, execution timing, and performance.
5. **Data Representation & Encodings**: Performing manual base conversions (Decimal, Binary, Hexadecimal), verifying in Python, building an interactive converter script, and analyzing ASCII and UTF-8 encodings.
6. **Version Control & GitHub Collaboration**: Creating feature branches (`update-about`), publishing pull requests, reviewing diffs, and understanding collaborative branching workflows.
7. **Computer Networking**: Analyzing LAN, MAN, WAN, routers, and client-server models, testing reachability with `ping` and `nslookup`, and tracing the 6-step lifecycle of loading a web page.

## Instructions for Running the Number Converter

The Python Number Converter developed in Mission 5 converts positive decimal integers into their corresponding binary (base 2) and hexadecimal (base 16) formats with built-in input validation.

### How to Run:

1. Open your Terminal and navigate to the `mission-05-numbers-data` folder:
   ```bash
   cd mission-05-numbers-data
   ```

2. Run the program using Python 3:
   ```bash
   python3 number_converter.py
   ```

3. Follow the on-screen prompt:
   - Enter any positive integer (e.g. `42`, `100`, `255`).
   - The program will display the binary and hexadecimal values.
   - Enter `q` to quit the program.
