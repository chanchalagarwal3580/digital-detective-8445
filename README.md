## Project Overview

This repository contains my completed work for **The Digital Detective** Diwali Independent Learning Assignment. The goal of this assignment is to explore and document how a modern computer works from the ground up:
- Understanding basic computer architecture and the IPOS (Input, Processing, Output, Storage) cycle.
- Navigating and manipulating files using the Unix command-line interface (Terminal).
- Inspecting how operating systems manage processes, storage, memory, and permissions.
- Understanding how source code is translated and executed by comparing compilers and interpreters.
- Analyzing data representation (binary, hexadecimal, decimal) and character encodings (ASCII, UTF-8), backed by a Python conversion tool.
- Practicing professional version control with Git and collaboration using GitHub (branches, commits, pull requests).
- Demystifying computer networking, DNS resolution, and the client-server lifecycle.

Each mission is documented in its own dedicated folder with clear explanations, real Terminal observations, and privacy-safe evidence.

## My Learning

Throughout this assignment, I have progressed from basic conceptual definitions to practical hands-on systems programming and version control. Here are three major highlights:

1. **Command-Line Precision & Safe File Operations**:
   I learned how to navigate Unix systems without relying on a mouse. Mastering flags like `ls -lah` and non-destructive redirection (`>>` vs `>`) demonstrated how developers inspect system states and chain commands together using pipes (`|`).

2. **Operating System Resource & Process Management**:
   I discovered that hundreds of background processes and daemons run continuously behind the desktop. Inspecting Process Identifiers (PIDs) and POSIX file permissions (`r-w-x`) revealed how the OS isolates applications and protects sensitive system files.

3. **Data Representation & Number Systems**:
   Building `number_converter.py` bridged theory with code, showing how transistors physically store bits, why hexadecimal is essential for representing memory addresses and bytes cleanly, and how character encodings like UTF-8 allow global communication.
